> 一个完全属于你的 AI 伙伴
> 不用 QQ，不用微信 —— 谁也封不了她

## 这是什么

一套自托管的 AI 陪伴系统

**她会：**
- 有自己的性格
- 记住你说过的话
- 有情绪，会因为你不理她而难过
- 偶尔主动找你

**你的东西都是你的：**
- 聊天记录存在**你自己电脑**上
- 人格是**你自己写**的
- 想改什么都行

## 快速开始

### 你需要

- Node.js 18+
- 一个 DeepSeek API Key（[去申请](https://platform.deepseek.com)）

### 三步跑起来

```bash
# 1. 配密钥
cp .env.example .env
# 编辑 .env，填上 API_KEY

# 2. 启动
node bridge.mjs

# 3. 看到这个就成了
# === 网桥起来了 === http://127.0.0.1:8787
# 口令在 data/token.txt
```

第一次启动会生成一把**主口令**，存在 `data/token.txt`
手机 App 连电脑时要填它

## 手机 App

安卓 App 源码在 `android/` 目录

**编译需要：**
- Android SDK（build-tools 34 + platform 34）
- JDK 17

```bash
bash android/build.sh
```

产物在 `android/build/`

**装好之后：**
1. 打开 App，填电脑的 IP
2. 端口填 `8787`
3. 口令填 `data/token.txt` 里那串
4. 左上角绿点亮了就是通了

**不在同一个 WiFi？**

这个项目本身不做内网穿透 —— 它只在电脑上开一个本地端口（`8787`），同一个 WiFi 下手机直接连就行。

要在外面（不同网络）用，得自己另外做内网穿透，常见两种：

- [Tailscale](https://tailscale.com)：装完电脑和手机就进同一个虚拟局域网了，App 里填 Tailscale 给的 IP
- 其他穿透工具（frp、cpolar、ngrok 之类）：把 `8787` 端口映射出去，填映射出来的地址

**注意：开穿透就等于把这个端口暴露到公网。** 主口令是唯一的门，别设太短，也别随手发给别人。

## 电脑控制面板（可选）

装进 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的侧栏面板，可以在电脑上管理她

源码在 `dsh-xiaojing-panel/`

```bash
dsh plugin --profile desktop add file:你的路径/dsh-xiaojing-panel
```

装完要去插件列表**启用**，然后重启 DSH

## 功能

### 聊天

- 文字、图片、表情包
- 引用回复、重新生成、删除
- 聊天记录导出

### 她的人格

- 用 Markdown 写
- 可以随时换（多个文件切换）
- 不用重装

### 情绪系统

十根情绪轴，会随对话变化：

```
温暖 委屈 想你 生气 害怕
黏人 累   吃醋 骄傲 记仇
```

**顶上那个「想你 65%」就是这里面最大的那个**

### 记忆

- 自动记住重要的事
- 会提炼「你是什么样的人」
- 可以手动触发重新分析

### 主动找你

她会在合适的时候自己发消息，不是在等你说话

### 钥匙系统

别人的机器人想跟她聊，不用给他你的主口令：

| 钥匙 | 权限 |
|------|------|
| `owner` | 全部（主口令） |
| `chat` | 能聊天，不能改配置 |
| `read` | 只能看，不能发 |

## 安全

**开源之前做过完整审计**（见 [AUDIT.md](AUDIT.md)）：
- 源码里没有硬编码任何密钥
- 路径穿越有三道防护（实测 5 种攻击全部拦截）
- 请求体有大小限制
- 所有网络请求都有超时

**你要注意：**
- ⚠️ **别把 `.env` 传给别人**（里面有你的 API Key）
- ⚠️ **别把 `data/` 传到公开的地方**（里面有聊天记录）
- ⚠️ 网桥默认监听 `0.0.0.0`，同一局域网内的设备能访问 —— 口令是 32 位十六进制，暴力猜不可能，但别截图发出去

## 常见问题

### 她不说话

1. 网桥在跑吗？（`node bridge.mjs`）
2. API 余额够吗？
3. `.env` 里 `API_KEY` 填了吗？

### 手机连不上

1. 手机和电脑同一个 WiFi 吗？
2. 电脑 IP 变了吗？（`ipconfig` 查）
3. 防火墙拦了吗？（允许 node.exe 通过）

### 她想发很远

改模型：

```ini
MODEL=deepseek-v4-pro
```

更贵但更聪明

### 怎么省钱

```ini
MODEL=deepseek-flash
HISTORY_TURNS=8
```
