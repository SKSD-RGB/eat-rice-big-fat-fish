# 表情包接口

> 这个项目**不自带表情包**。你需要自己准备。
> 这里说明怎么放、怎么用。

---

## 表情放哪

```
public/stickers/
├── 表情1.png
├── 表情2.gif
├── 表情3.jpg
└── nk/              ← 可选，放另一个来源的表情
    └── 表情4.png
```

**就这么简单** —— 把图片丢进这个文件夹，重启网桥，自动就被识别了。

**支持的格式**：png / jpg / gif / webp

---

## 手机 App 里怎么显示

App 会调这个接口拿清单：

```
GET /app/stickers
```

返回：

```json
{
  "ok": true,
  "count": 24,
  "gallery": [
    { "url": "/stickers/abc123.png", "name": "abc123" },
    { "url": "/stickers/nk/xyz.gif", "name": "xyz" }
  ]
}
```

**App 里点 ☺ 就能看到这些表情，点一下就发出去。**

---

## 她怎么发表情

在人格文件里告诉她的表情名字，她就会用。

**实际发出来长这样：**

```
哈哈 ![表情](/stickers/abc123.png) 笑死
```

**App 会自动把那个 markdown 渲染成图片。**

### 怎么让她知道有哪些表情

`stickers.mjs` 会把表情清单塞进提示词。她在回复时可能会挑一个用。

**想控制她能用哪些**：在人格文件里写

```markdown
## 表情

你能用的表情有：笑、哭、生气、害羞、睡觉
对应的文件在 /stickers/ 下面。
想表达情绪的时候可以发一个。
```

## 换成你自己的表情

### 方法 1：直接丢文件

把图拖进 `public/stickers/`，重启网桥。

**文件名无所谓** —— 会自动列出来。

### 方法 2：批量导入

```bash
# 从某个文件夹批量拷进来
cp ~/Downloads/my-stickers/*.png public/stickers/
```

### 方法 3：用 API 上传（App 里发图那个接口）

App 里「＋」发图的功能走的是：

```
POST /app/image
```

那个会把图存到 `public/uploads/`，那是**你发的图**，不是表情包。

---

## 表情数量建议

| 数量 | 效果 |
|------|------|
| 0 个 | 她只发文字，不会发表情 |
| 10-30 个 | 够用，挑得准 |
| 50-100 个 | 变化多，但提示词会变长 |
| 200+ 个 | 提示词太长了，token 会浪费 |

**建议 30-60 个就够。**

---

## 表情从哪来

**这个文件不会告诉你。**

你需要自己找。常见方式：

- 自己做
- 用开源表情库
- 用你喜欢的角色的图（注意版权）

**⚠️ 注意版权**：别把别人的作品当成自己的开源出去。

## 技术细节

### 目录结构

```
public/stickers/       主目录
public/stickers/nk/    子目录（可选，另一个来源）
```

**为什么要 `nk/` 子目录？**
因为有时候你会从两个地方收表情，分开管理方便。

### 访问路径

```
/stickers/文件名
/stickers/nk/文件名
```

### 安全限制

- 路径里的 `..` 会被拦截（防止穿越目录）
- 只读，不能通过接口写文件
- 没有鉴权（表情是公开的）

---

## 检查是否生效

```bash
curl http://127.0.0.1:8787/app/stickers
```

能看到 `"count": 数字` 就对了。

**如果 count 是 0**：
- 检查 `public/stickers/` 里有没有图
- 检查文件扩展名是不是 png/jpg/gif/webp
- 重启网桥

---

**放几张图进去试试，这是最快能看出效果的定制项。**
